yanolja rating crawler

### 📌 프로젝트 개요

이 프로젝트는 야놀자 웹사이트에서 호텔의 이름, 평점, 간단한 설명 정보를 크롤링하여 구조화된 데이터로 수집합니다.

### 🛠 사용 기술 및 도구

- **Python**, **Pandas**, **NumPy**
- **BeautifulSoup**, **Requests** – 웹 크롤링
- **Matplotlib**, **Seaborn** – 시각화
- **CSV 파일 처리 및 병합**
- **Selenium** *(필요 시)* – 동적 페이지 크롤링

### 💡 기대 효과 및 활용 방안

- 다양한 숙소의 이름과 평점 데이터를 구조화함으로써, 호텔/펜션에 대한 정량적 비교와 트렌드 분석이 가능해집니다.
- 수집된 데이터를 기반으로 사용자 맞춤형 추천 시스템 또는 지역별 평점 통계 시각화 등에 활용할 수 있습니다.
- 웹 크롤링, 데이터 수집, 전처리, 시각화에 이르는 전체 파이프라인을 학습하거나, 여행/숙박 관련 데이터 분석 프로젝트의 기초 자료로 활용할 수 있습니다.
- 향후 감성 분석, 가격 비교, 리뷰 요약 등 고도화된 데이터 분석 및 서비스 개발로 확장할 수 있습니다.
